# StyleFit 

A smart virtual fashion platform where users can:
- Try outfits on avatar
- Buy & sell clothes
- Get outfit recommendations
- Earn rewards

## Tech Stack
- React
- Figma
- GitHub

## Features
- Avatar try-on
- Buy & sell system
- Match outfits
- Gamification (likes → coupons)
